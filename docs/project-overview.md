# 项目概览

## 项目名称

Rescue Xiaoan

## Slogan

人到不了的地方，让它先找到生命。

## 一句话说明

一套通过 360° 视频、现场音频和多模态 AI 帮助救援人员更快发现受困者、理解风险并采取行动的智能搜救机器狗系统。

## 问题

地震和坍塌现场可能存在二次坍塌、积水、狭窄通道与结构遮挡。救援人员无法在缺少信息时贸然进入，而传统视频回传只能提供画面，仍需指挥人员自行寻找受困者、判断风险和组织行动。

## 方案

Rescue Xiaoan 让搭载 Insta360 X4 与 RDK 的机器狗先进入危险区域。系统持续接收 360° 视频和现场音频，主动识别疑似受困人员，对可观察的意识回应、活动能力、受压情况、外貌特征与环境风险进行结构化整理，并向指挥中心回传人员队列、定位线索和行动建议。当前演示由现场操作员手动遥控机器狗完成移动侦察。

## 黑客松现场完成内容

- 完成机器狗、全景相机与边缘计算设备的组合。
- 接入 360° 视频及现场音频信息流。
- 完成多模态 AI 对连续信息的理解与结构化输出设计。
- 建立人员识别、环境风险和救援优先级规则。
- 完成救援组任务与机器狗侦察任务的并行决策界面。
- 完成从进入现场、发现人员、分析风险到输出建议的演示闭环。
- 机器狗未开放 SDK，因此本次移动和绕行由人员手动遥控；机械臂因硬件故障未进入演示闭环。

## 使用方式

1. 将机器狗投放至救援人员难以安全进入的区域，由现场人员手动遥控移动。
2. 操作员遥控机器狗侦察，系统回传视频、音频和设备状态。
3. AI 发现疑似受困人员，生成独立目标档案。
4. 系统展示人员状态、环境风险、定位和证据。
5. 指挥人员确认建议，分别向救援组和机器狗操作员下发任务。
6. 操作员遥控机器狗继续绕行补充视角，或将补给运送至意识清醒且可自主取用的受困人员附近。
