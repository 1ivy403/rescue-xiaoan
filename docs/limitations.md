# 能力边界

- 系统不直接测量心率、血氧、血压等医学生命体征，除非接入经过验证的专用传感器。
- “意识清醒”“能够活动”等描述来自可观察动作或语音回应，不构成医疗诊断。
- 360° 相机提供全景覆盖，但墙体、梁体、烟尘和碎石仍会造成遮挡。
- 室内定位的准确度取决于机器狗地图、SLAM、现场标记和实际传感器配置。
- AI 可能漏检、误检或错误理解声音；低置信度目标必须保持“待确认”。
- 救援优先级、路线、结构支撑和补给方案必须由专业人员确认。
- 演示界面包含模拟救援数据，用于说明产品工作流，不代表已经通过真实灾害现场验证。
- VBot 未开放 SDK，当前机器狗移动与绕行由现场操作员手动遥控。
- 机械臂因硬件故障未进入本次演示闭环。
