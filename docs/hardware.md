# 硬件组成

| 硬件 | 在系统中的职责 | 是否进入核心闭环 |
| --- | --- | --- |
| VBot 机器狗 | 进入废墟、移动侦察、绕行补充视角、搭载补给；当前由操作员手动遥控 | 是 |
| Insta360 X4 | 获取 360° 现场画面和录制素材 | 是 |
| RDK S3 | 设备接入、边缘处理、通信与任务编排 | 是 |
| 麦克风 | 获取呼救、回应和现场环境声音 | 是 |
| 补给包 | 携带饮用水、保温物资等应急用品 | 补充能力 |
| 机械臂或执行机构 | 原计划辅助递送或操作；因硬件故障未进入本次演示 | 未实现 |

相机、数据线、电池、存储卡和固定结构共同构成完整的现场演示配置。任何设备的拆装和使用均遵守主办方与供应商要求。

VBot 当前未开放 SDK，系统不会自动控制机器狗移动。指挥界面给出的绕行与侦察任务由现场操作员手动执行。
