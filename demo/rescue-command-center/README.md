# Rescue Command Center Demo

这是 Rescue Xiaoan 面向救援指挥人员的模拟用户界面。

直接打开 `index.html` 即可查看，页面所需图片和视频均保存在当前目录的 `assets/rescue/` 中，不依赖本机绝对路径或外部 CDN。

界面重点展示：

- 发现人数、立即救援人数和状态未知人数。
- 救援组与机器狗并行执行的当前任务。
- 360° 现场视频与视频、音频理解流。
- P-03、P-01 和 P-02 的救援优先级队列。
- 目标详情、环境风险、撤离建议和补给建议。

页面内的人物状态与救援数据为演示场景数据，用于说明信息组织和决策流程。
