# 项目说明

## 项目名称

Rescue Xiaoan

## Slogan

人到不了的地方，让它先找到生命。

## 解决的问题

地震与坍塌现场存在进入风险高、视觉遮挡多和原始信息难以及时转化为行动的问题。救援人员需要的不只是更多画面，而是能够快速回答“发现了谁、谁最危险、下一步做什么”的现场结论。

## 解决方案

Rescue Xiaoan 将 VBot 机器狗、Insta360 X4、RDK 和多模态 AI 组合为智能搜救系统。操作员手动遥控机器狗进入危险区域，持续回传 360° 视频与音频；AI 主动发现疑似受困人员，整理可观察状态、环境风险、定位线索和救援优先级；指挥中心再将结果转化为救援组与机器狗操作员的并行任务。

## 现场完成内容

- 完成机器狗、全景相机与计算设备的硬件组合。
- 接入视频与音频信息流。
- 完成多模态理解和结构化输出设计。
- 建立人员识别、环境风险、优先级和人工确认规则。
- 完成救援指挥中心模拟用户界面。
- 跑通从进入现场到输出行动建议的演示闭环。
- 机器狗未开放 SDK，现场采用手动遥控；机械臂因硬件故障未进入闭环。

## 使用方式

操作员遥控机器狗进入受灾区域并持续侦察；系统识别疑似受困人员并建立目标档案；指挥人员查看证据、风险与优先级，确认后分别向救援组和机器狗操作员下发任务。操作员可以遥控机器狗继续绕行补充视角，也可以将补给运送至符合条件的受困人员附近。

## 核心价值

让机器狗先进入危险现场，让救援人员在行动前获得完整、结构化、可执行的现场信息。
