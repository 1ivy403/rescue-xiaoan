# Showcase

本目录保存评审可直接查看的展示素材：

- `videos/`：救援场景作业、模拟用户界面和现场技术接入演示。
- `screenshots/`：指挥中心总览、人员详情和技术流关键画面。
- `poster/`：易拉宝、A4 导览和项目海报。
- `ui-assets/`：用于展示界面的图片和视觉素材。

公开视频使用 H.264/AAC MP4，图片优先使用 PNG 或高质量 JPG。保留最终交付文件，不提交剪辑缓存和中间工程。
